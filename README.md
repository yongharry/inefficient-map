# 🚇 비효율 지도 (Inefficient Map)

> **조금 늦어도, 창밖이 좋은 길로.**

**비효율 지도**는 목적지까지 가장 빨리 도착하는 경로뿐 아니라, **이동 중 좋은 풍경을 만날 수 있는 서울 지하철 경로**를 추천하는 오픈소스 프로젝트입니다.

**프로젝트 상태:** 기획 및 개발 환경 구축 단계  
**개발 언어:** Python  
**개발 환경:** Anaconda / Spyder  
**교통수단:** 지하철 (도보 관광·버스 경로는 현재 범위에서 제외)

---

## 1. 프로젝트 소개 (Overview)

기존 길 찾기 서비스는 주로 최단시간, 최단거리, 최소 환승을 중심으로 경로를 추천합니다. 하지만 이동할 때 언제나 가장 빨리 도착하는 것이 최선은 아닐 수 있습니다.

**비효율 지도 (Inefficient Map)**는 사용자가 출발역과 도착역을 입력하면, 허용한 추가 이동시간 안에서 **지상철 구간이나 한강 횡단 구간을 경험할 수 있는 대체 경로**를 탐색하는 것을 목표로 합니다.

핵심 질문은 다음과 같습니다.

> **"10분쯤 더 걸리더라도 한강 풍경을 보면서 갈 수는 없을까?"**

이 프로젝트는 이동시간의 효율성을 포기하는 것이 아니라, **시간뿐 아니라 이동 경험도 경로 선택의 기준으로 삼는 것**을 지향합니다.

## 2. 개발 동기 (Motivation)

서울에 올라온 뒤 지상철을 타며 도시 풍경을 바라보는 경험이 인상 깊었습니다. 특히 지하철이 한강 위를 지날 때 차창 밖으로 펼쳐지는 풍경은 일상적인 이동을 작은 여행처럼 느끼게 했습니다.

이 경험을 바탕으로, 출발지와 목적지가 정해진 상황에서도 **아름다운 풍경을 보기 위해 조금 돌아가는 선택지**를 제공하고자 이 프로젝트를 기획했습니다.

## 3. 주요 기능 (Key Features)

아래 기능은 **구현 목표**이며, 현재 완성된 기능을 의미하지 않습니다.

| 기능 | 설명 | 상태 |
| --- | --- | --- |
| 최단경로 계산 | 출발역부터 도착역까지 소요시간이 짧은 경로 탐색 | 개발 예정 |
| 지상철 구간 분석 | 지상 운행 여부를 경로 평가에 반영 | 개발 예정 |
| 한강 횡단 구간 분석 | 한강을 건너는 지하철 구간에 풍경 가점 부여 | 개발 예정 |
| 풍경 우선 경로 추천 | 허용시간 안에서 풍경 점수가 높은 경로 탐색 | 개발 예정 |
| 추가 이동시간 설정 | 사용자가 감수할 우회시간 선택 | 개발 예정 |
| 경로 비교 및 시각화 | 최단경로와 추천 경로의 시간·특징 비교 | 개발 예정 |

### 향후 확장 아이디어

- **노을·야경:** 일몰 시각과 예상 통과 시각을 고려한 추천
- **축제·행사:** 행사 일정과 위치를 참고한 특별 경로 탐색
- **계절별 풍경:** 벚꽃, 단풍 등 계절 요소 반영
- **차창 방향:** 진행 방향에 따른 주요 풍경 안내
- **혼잡도:** 이동 쾌적성을 고려한 추천

확장 기능은 핵심 경로 추천 기능을 구현한 뒤 추가 여부를 결정합니다.

## 4. 작동 원리 (How It Works)

지하철 노선을 **그래프(Graph)**로 표현할 계획입니다.

- **Node(정점):** 지하철역 또는 노선별 승강장
- **Edge(간선):** 역 사이의 이동 및 환승 연결
- **Weight(가중치):** 이동시간과 풍경 점수

예상 경로 계산 과정은 다음과 같습니다.

1. 출발역과 도착역 사이의 **최단경로**를 계산합니다.
2. 사용자가 허용한 **추가 이동시간**을 확인합니다.
3. 허용시간을 만족하는 **대체 경로 후보**를 탐색합니다.
4. 각 경로의 **지상 구간, 한강 횡단 등 풍경 요소**를 평가합니다.
5. 풍경 점수가 높은 경로를 최단경로와 **비교하여 제시**합니다.

알고리즘의 기본 목표는 다음과 같습니다.

**허용된 추가 이동시간 안에서 풍경 점수가 가장 높은 경로를 찾는다.**

구체적인 풍경 점수 산정 방식과 탐색 알고리즘은 구현 및 테스트 과정에서 확정할 예정입니다. 적절한 대체 경로가 없다면 무리하게 우회 경로를 추천하지 않습니다.

## 5. 개발 범위 (Scope)

첫 버전은 **서울 지하철**을 대상으로 하며, **2호선 순환선**에서 경로 탐색 기능을 먼저 시험할 계획입니다. 이후 다른 노선과 환승 경로로 확장합니다.

현재 범위에는 **버스 길 찾기, 목적지 없는 관광 코스, 중간 하차 후 도보 산책**이 포함되지 않습니다.
