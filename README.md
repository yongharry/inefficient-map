# 🚇 비효율 지도 (Inefficient Map)

> **조금 늦어도, 창밖이 좋은 길로.**

**비효율 지도**는 목적지까지 가장 빨리 도착하는 경로뿐 아니라, **이동하는 동안 좋은 풍경을 만날 수 있는 서울 지하철 경로**를 추천하는 것을 목표로 하는 오픈소스 프로젝트입니다.

**프로젝트 상태:** STEP 1 완료 — 2호선 순환선 최단경로 탐색 프로토타입  
**개발 언어:** Python  
**개발 환경:** Anaconda / Spyder  
**대상 교통수단:** 지하철 (도보 관광·버스 경로는 현재 범위에서 제외)

> **안내:** 현재 공개된 프로그램은 풍경 추천 기능이 없는 학습용 프로토타입입니다. 역간 이동시간도 실제 운행시간이 아닌 **구간당 2분의 가정값**을 사용하므로 실제 길 찾기에 사용하면 안 됩니다.

## 1. 프로젝트 소개 (Overview)

기존 길 찾기 서비스는 주로 최단시간, 최단거리, 최소 환승을 중심으로 경로를 안내합니다. 하지만 이동할 때 언제나 가장 빨리 도착하는 것이 최선은 아닐 수 있습니다.

**비효율 지도 (Inefficient Map)**는 사용자가 출발역과 도착역을 입력하면, **허용 가능한 추가 이동시간** 안에서 지상철과 한강 횡단 구간 등 **이동 중 풍경을 감상할 수 있는 대체 경로**를 탐색하는 것을 최종 목표로 합니다.

> **“10분쯤 더 걸리더라도 한강 풍경을 보면서 갈 수는 없을까?”**

이 프로젝트는 이동을 일부러 느리게 만드는 것이 아니라, **시간뿐 아니라 이동 경험까지 경로 선택의 기준으로 삼는 것**을 지향합니다.

## 2. 개발 동기 (Motivation)

서울에 올라온 뒤 지상철을 타며 도시 풍경을 바라보는 경험이 인상 깊었습니다. 특히 지하철이 한강 위를 지날 때 차창 밖으로 펼쳐지는 풍경은 일상적인 이동을 작은 여행처럼 느끼게 했습니다.

이 경험에서 출발해, 목적지가 정해진 상황에서도 **아름다운 풍경을 보기 위해 조금 돌아가는 선택지**를 제공하는 프로그램을 기획했습니다.

## 4. 현재 구현 내용 — STEP 1 (Implementation)

### 그래프 구조

현재 구현은 서울 지하철 **2호선 본선 순환선 43개 역**을 다룹니다.

- **Node(정점):** 지하철역 하나
- **Edge(간선):** 인접한 두 역을 잇는 양방향 이동 관계
- **Weight(가중치):** 역 사이의 이동시간. 현재는 모든 구간에서 **2.0분으로 가정**

마지막 역과 첫 번째 역을 연결하여 순환 구조를 만들었습니다. **성수지선, 신정지선, 다른 노선으로의 환승, 열차 대기시간은 포함하지 않습니다.**

### 최단경로 탐색 알고리즘

[`inefficient_map_step1.py`](inefficient_map_step1.py)에서는 Python 표준 라이브러리 `heapq`를 사용하여 **다익스트라(Dijkstra) 알고리즘**을 구현했습니다.

1. 출발역의 누적시간을 0으로, 나머지 역을 무한대로 초기화합니다.
2. 우선순위 큐에서 누적시간이 가장 작은 역을 꺼냅니다.
3. 인접 역까지의 새로운 누적시간을 계산해 더 짧은 경우 갱신합니다.
4. 도착역에 도달하면 기록된 이전 역을 역추적하여 경로를 구성합니다.
5. 경로, 이동 구간 수, **테스트용 추정시간**을 출력합니다.

현재 모든 구간의 가중치가 같기 때문에 결과는 사실상 **이동 구간 수가 최소인 경로**입니다. 실제 최단 *운행시간* 경로와는 다를 수 있습니다.

### STEP 1의 한계

- 모든 역간 시간을 2분으로 가정합니다.
- 실시간 열차 위치, 실제 배차·정차·대기시간을 반영하지 않습니다.
- 2호선 순환선 본선만 지원하고 환승은 지원하지 않습니다.
- **아직 풍경 점수 계산이나 비효율 경로 추천은 구현되지 않았습니다.**

## 5. 향후 추천 알고리즘 (Planned Scenic Routing)

향후에는 최단경로의 소요시간을 기준으로 **추가 이동시간 제한**을 적용하고, 그 안에서 풍경 점수가 높은 대체 경로를 찾는 방식을 개발할 예정입니다.

예를 들어 최단경로가 30분이고 사용자가 10분의 우회를 허용하면, 예상 이동시간 40분 이내의 후보 중 풍경 점수가 높은 경로를 추천하는 식입니다. 이 수치는 **개념 설명용 예시**입니다.

풍경 점수에는 지상 구간, 한강 횡단, 도시 전망 등을 반영하는 방안을 검토하고 있습니다. 점수 계산 규칙과 대체 경로 탐색 기법은 향후 실험을 통해 구체화합니다. 의미 있는 대체 경로가 없으면 무리한 우회를 추천하지 않도록 설계할 계획입니다.

## 6. 설치 및 실행 (Installation & Usage)

### 요구 사항

- Python 3.x (Spyder의 Python 3.14 환경에서 실행 화면 확인)
- 추가 외부 패키지 설치 **불필요** (`heapq`는 Python 표준 라이브러리)

### 실행 방법

**방법 A — Spyder**

1. 저장소를 클론하거나 ZIP으로 다운로드합니다.
2. Spyder에서 [`inefficient_map_step1.py`](inefficient_map_step1.py)를 엽니다.
3. 실행 버튼 또는 `F5`를 누릅니다.
4. IPython Console에서 출발역과 도착역을 차례로 입력합니다.

**방법 B — 명령 프롬프트/터미널**

```bash
python inefficient_map_step1.py
```

### 입력 및 출력 예시

```text
=== 비효율 지도: 2호선 최단경로 (STEP 1) ===
2호선 본선 43개 역 / 지선 제외
주의: 역간 2분을 가정한 학습용 시간입니다.

출발역 (예: 합정): 합정
도착역 (예: 잠실): 당산

--- 계산 결과 ---
출발역: 합정
도착역: 당산
최단경로: 합정 → 당산
이동 구간 수: 1
테스트용 추정시간: 2분
※ 실제 배차·정차·대기시간이 반영되지 않았습니다.
```

이 출력은 **프로그램의 계산 결과를 보여 주기 위한 테스트 예시**이며 실제 운행시간 안내가 아닙니다.
